- Task-F02: operation map, Dart vs TypeScript (`colorUtils.ts` / `colorHarmony.ts`). `_mod(x, m)` = `(x.remainder(m) + m).remainder(m)` mirrors `mod(x, m)` = `((x % m) + m) % m`, used at all four sites: rgbToHsv `60 * _mod((g - b) / d, 6)` = `60 * mod((g - b) / d, 6)`; rgbToHsv `h: _mod(h, 360)` = `h: mod(h, 360)`; hsvToRgb `_mod(h, 360) / 60` = `mod(h, 360) / 60`; hsvToRgb `c * (1 - (_mod(hPrime, 2) - 1).abs())` = `c * (1 - Math.abs(mod(hPrime, 2) - 1))`.
